# Expense Tracker

## 📌 Project Description
Expense Tracker is a web application developed using Flask and MySQL. It helps users manage their daily expenses by adding, editing, viewing, and deleting expense records.

## 🚀 Features
- User Registration
- User Login
- Add Expense
- View Expenses
- Edit Expense
- Delete Expense
- Total Expense Calculation
- Expense Analysis Chart
- Bootstrap Responsive UI

## 🛠 Technologies Used
- Python
- Flask
- MySQL
- HTML
- CSS
- Bootstrap
- Matplotlib
- Git & GitHub

## ▶️ How to Run

```bash
pip install -r requirements.txt
python app.py
```

Then open:

```
http://127.0.0.1:5000
```
